# ai-study-assistant
NLP system that generates summaries, flashcards, keywords, and quizzes from notes or textbooks. Users can upload pdf or text files, or they can just paste in text.

# download dependencies
Python libraries:
spaCy
PyMuPDF
transformers
torch
nltk
flask
flask-cors
werkzeug

You can use:
pip install transformers torch spacy PyMuPDF nltk flask flask-cors werkzeug

# backend
cd ai-study-assistant/backend

python app.py

# frontend
Open folder in vs code

install extension live server(Ritwick Dey)

right click index.html and click "Open with live server"
